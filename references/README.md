# Reference Library

These files are supplied technical/visual references.

They are not global project rules.

Use `../EXAMPLE-INDEX.md` to choose the smallest relevant reference set and `REFERENCE-MANIFEST.json` for machine-readable metadata.

Do not edit historical references merely to remove warnings unless reference-library maintenance is the explicit task.

A reference may contain legacy values such as fixed widths, old breakpoints, placeholder links/media, or brand-specific values. New work must normalize those values to current project rules.

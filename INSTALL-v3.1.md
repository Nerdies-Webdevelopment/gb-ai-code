# Installation – ab Paket 3.2.0

Die vollständige aktuelle Anleitung einschließlich aller Abhängigkeiten steht in
[README.md](README.md). Dieser Dateiname bleibt für ältere Verweise erhalten.

1. Bestehende WordPress-Installation und eigene Dateien sichern.
2. Gesamtpaket-ZIP entpacken; dessen Inhalt direkt neben wp-admin und wp-config.php kopieren.
3. Vorhandene eigene Anweisungen und Theme-Dateien zusammenführen.
4. GeneratePress und GenerateBlocks installieren/aktivieren; Pro-Erweiterungen nur bei Bedarf.
5. Mitgeliefertes Child Theme bei Bedarf aktivieren; WordPress-Ordner in Codex öffnen.
6. Optional START-HIER.cmd oder `python tools/setup_project.py` ausführen.

Keine festen Benutzer-/Installationspfade, keine Datenbankinstallation, kein Plugin-Upload
des Gesamtpakets, keine automatischen Seitenänderungen. Python 3.10+ für die Werkzeuge.
